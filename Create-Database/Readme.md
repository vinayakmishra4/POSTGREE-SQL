# 🐘 Create Database in PostgreSQL

> A beginner-friendly guide to creating a PostgreSQL database using **pgAdmin**.

![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Database-4169E1?style=for-the-badge&logo=postgresql&logoColor=white)
![pgAdmin](https://img.shields.io/badge/pgAdmin-Tool-336791?style=for-the-badge&logo=postgresql&logoColor=white)

---

## 📌 Overview

In this tutorial, we will create a new PostgreSQL database named **`learning`** using **pgAdmin**.

### 🎯 Database Configuration

| Setting | Value |
|---|---|
| 🗄️ Database | `learning` |
| 👤 Owner | `Adam` |
| 🔤 Encoding | `UTF8` |
| 🔗 Connection Limit | `-1` |
| 📂 Default Schema | `public` |

---

## 🚀 1. Open pgAdmin

Open **pgAdmin** and connect to your PostgreSQL server.

In the left panel, navigate to:

```text
Servers
└── PostgreSQL
    └── Databases
```

You will normally see a default database named:

```text
postgres
```

---

## 🗄️ 2. Create a Database

Right-click **Databases** and select:

```text
Create → Database
```

A **Create - Database** window will open.

---

## ⚙️ 3. Configure the Database

Enter the following values:

### Database Name

```text
learning
```

### Owner

Change the default owner from:

```text
postgres
```

to:

```text
Adam
```

### Encoding

Keep the encoding as:

```text
UTF8
```

UTF-8 allows PostgreSQL to store text from different languages, such as:

```text
English → Hello
Hindi   → नमस्ते
Arabic  → مرحبا
Chinese → 你好
```

### Connection Limit

Keep the connection limit as:

```text
-1
```

In PostgreSQL, `-1` means there is no specific connection limit configured for the database.

---

## 💾 4. Save the Database

After configuring the database:

**Click → Save**

Your new database will appear under **Databases**:

```text
📦 learning
```

---

## 📁 5. Explore the Database

Expand the `learning` database:

```text
learning
└── Schemas
    └── public
```

PostgreSQL automatically creates a default schema called:

```text
public
```

We will use this schema to create our tables.

---

## 🧩 What Is a Schema?

A **schema** is a logical container used to organize database objects such as tables, views, and functions.

For example:

```text
learning
└── Schemas
    └── public
        ├── users
        ├── products
        └── orders
```

Schemas make it easier to organize database objects as a project grows.

---

## 💻 SQL Equivalent

The database can also be created using SQL:

```sql
CREATE DATABASE learning
    WITH
    OWNER = Adam
    ENCODING = 'UTF8'
    CONNECTION LIMIT = -1;
```

> 💡 The exact SQL generated by pgAdmin may vary depending on your PostgreSQL version and configuration.

---

## 🗂️ Final Structure

After creating the database, the basic structure is:

```text
🐘 PostgreSQL Server
│
└── 📦 learning
    │
    └── 📁 Schemas
        │
        └── 📂 public
            │
            └── 📋 Tables
```
