<details open>
<summary><b>3️⃣ Module 3 — <a href="https://github.com/vinayakmishra4/POSTGREE-SQL/blob/main/Configure-Login-User/Readme.md">Configuring Login User</a></b></summary>
<br>

- Exploring the PostgreSQL server in pgAdmin and how databases, roles, and server settings are organized
- Understanding the default `postgres` superuser account and what superuser access allows
- Creating a new login role through pgAdmin's Login/Group Roles panel, with a secure password
- Configuring role privileges: login access, superuser status, role creation, database creation, and replication
- Applying the principle of least privilege when assigning permissions to a role
- Exploring role membership for grouping users (e.g. developers, analysts, admins, read-only users)
- Using pgAdmin's SQL preview to see the underlying `CREATE ROLE` statement generated by the GUI, then verifying the role's properties afterward

</details>

<details open>
<summary><b>4️⃣ Module 4 — <a href="https://github.com/vinayakmishra4/POSTGREE-SQL/tree/main/Create-Database">Create Database</a></b></summary>
<br>

- Creating a new database (e.g. `learning`) through pgAdmin's Databases panel
- Setting the database owner to a specific role instead of the default `postgres` user
- Choosing UTF-8 encoding to support multilingual text
- Understanding connection limits, including what an unlimited setting means
- Exploring the default `public` schema created automatically with a new database
- Understanding what a schema is and how it organizes tables, views, and other objects
- Recognizing the SQL equivalent (`CREATE DATABASE`) behind the actions performed in pgAdmin

</details>

<details open>
<summary><b>5️⃣ Module 5 — <a href="https://github.com/vinayakmishra4/POSTGREE-SQL/tree/main/Creating-Tables">Creating Tables</a></b></summary>
<br>

- Setting up a sample database with three related tables: `customers` (customer_id, first_name, last_name), `products` (product_id, product_name, unit_price), and `purchases` (purchase_id, product_id, customer_id)
- Running the provided SQL scripts (`Customertable.sql`, `Prouctstable.sql`, `Purchasetable.sql`) in pgAdmin's Query Tool to create each table and load sample data
- Defining a primary key for each table during creation
- Adding foreign key constraints on `purchases` to link it back to `customers` and `products`
- Refreshing and verifying new tables in pgAdmin after each script runs
- Visualizing how the three tables relate to each other ahead of learning joins and queries

</details>
